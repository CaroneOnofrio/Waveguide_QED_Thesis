# Waveguide QED Simulation
Numerical simulations for my Master Thesis: *"Photon Bunching and Antibunching in waveguide QED"*.

This repository contains the Python implementation used to simulate the dynamics of three quantum emitters coupled to a 1D waveguide, calculating transition amplitudes and bunching probabilities for a symmetrica initial state in the two-excitation sector.

## Features
- Numerical evaluation of decay rates and energy shifts.
- Bunching/Antibunching probability analysis as a function of the phase $\phi(\omega_0)$.
- Visualization tools for physical observables.

## Requirements
- `numpy`
- `scipy`
- `matplotlib`
